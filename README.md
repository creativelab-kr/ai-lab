# AI 경영 실험실 (AI Operations Lab)

준비 단계의 공개 실험 노트입니다. 사람은 결정하고 AI가 일하는 회사를 운영하며 남긴 기록과, 브라우저에서 바로 쓰는 계산 도구를 담습니다.

- 지금 있는 것: 글 1편, 영상 1편(자막 있음 · 목소리는 AI 음성), 도구 3개(작은 표본 판정 계산기 · 단계별 깔때기 계산기 · "끝났다"의 증거 점검표), 공개 장부, 콘텐츠 검색과 라이브러리
- 검수 중인 시안이라 검색 노출을 막아 두었습니다. 내용이 바뀔 수 있습니다.
- 정적 페이지입니다. 외부 글꼴·스크립트·분석 도구·쿠키가 없고, 도구에 넣은 숫자와 검색어는 브라우저 밖으로 나가지 않습니다. 첫 화면의 3D는 직접 쓴 WebGL입니다.
- 틀린 곳은 고치고 `ledger.html`의 정정 이력에 남깁니다.

A preview draft: measured records from a company where a person decides and AI agents do the work, plus small in-browser calculators. Static pages, no tracking.
